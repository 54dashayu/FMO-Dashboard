FMO 仪表盘下载

FMO 仪表盘是面向 FMO 用户的实时通联看板，集中展示当前发言、最近通联、友台位置、相对方位、距离、服务器状态、播报模式和通联统计。V2.0 已全面转向新版界面，桌面端和移动端都围绕实时使用场景重新整理。

网页版已全面转向 V2： 进入网页版 V2 。网页版适合临时访问或快速体验，长期使用强烈建议下载对应平台的 App 或桌面版，稳定性和兼容性更好。

V2.0 优化重点

  • Dashboard 第一屏重新设计，当前发言、最近通联、方位距离和服务器信息更集中。
  • 移动端顶栏、底部导航和页面安全区域重新适配，手机上更紧凑易读。
  • 新增最近活跃服务器切换、语音播报模式整理和多地址同步体验优化。
  • Windows / macOS 桌面版不依赖外部浏览器，减少自动 HTTPS 和浏览器安全策略影响。

使用建议

  • Windows 桌面版添加本地 FMO 地址时，建议填写设备局域网 IP，例如 192.168.x.x。
  • 部分 Windows 环境无法解析 fmo.local 这类 .local 地址，可能导致同步失败。
  • 当前 Windows 和 macOS 桌面测试包未配置商业签名证书，首次安装或打开时可能出现安全提示。
  • 如本站下载受限，可到 GitHub 项目页面查看 Release 附件。
