# FMO仪表盘 Windows 便携版

## 使用方法

1. 解压整个文件夹。
2. 双击 `start-windows-hidden.vbs`，会在后台启动并自动打开浏览器。
3. 浏览器会自动打开 FMO仪表盘。
4. 需要退出时，双击 `stop-windows.bat`。
5. 如果需要查看局域网访问地址或排查问题，再双击 `start-windows.bat`，这个方式会显示命令行窗口。

## 说明

- 这个包内置了 Windows 版 Node.js 运行时，目标电脑不需要安装开发环境。
- `Portable-x64` 面向 Win10/Win11 64 位用户；`Portable-x86` 面向 32 位 Windows 用户；`Legacy-Win7-x86` 仅作为 Win7 旧系统兜底包。
- `.exe` 版本是便携启动器，会自动准备运行目录并启动本地服务；它不是传统安装包，不需要安装向导。
- 本机默认访问地址是 `http://127.0.0.1:5180/`，如果端口被占用，会自动尝试后面的端口。
- 便携版默认允许同一局域网内的其他设备访问。通常手机浏览器可以打开 `http://电脑局域网IP:5180/` 访问，例如 `http://192.168.x.x:5180/`。
- 手机、运行便携版的电脑、FMO 设备需要在同一个局域网内。
- 如果 Windows 防火墙弹出提示，请允许 Node.js 在“专用网络”中通信。
- 如果浏览器没有自动打开，可改用 `start-windows.bat` 启动，查看命令行窗口里显示的地址，手动复制到浏览器。
- 初次使用时，请在 FMO仪表盘的设置里确认你的 FMO 地址。

## 安全提示与校验

- 便携版会启动本机 Web 服务并自动打开浏览器，这是正常行为。
- 正式发布的 `.exe` 启动器应当进行代码签名；未签名测试包可能触发 Windows SmartScreen 或部分杀毒软件的未知发布者提示。
- 如果 `.exe` 被拦截，可下载 `.zip` 版本，解压后运行 `start-windows-hidden.vbs` 或 `start-windows.bat`。
- 发布页会提供 SHA256 校验值。可在 PowerShell 中执行：

```powershell
Get-FileHash .\FMO-Dashboard-Windows-Portable-x64-v2.0.0.exe -Algorithm SHA256
```

校验值应与发布页提供的一致。

## 本版本改进

- V1.0.0 集中修复网页版、Win64 便携版和安卓端的实时通联状态同步问题。
- 最近通联列表中已通联呼号可直接打开通联卡片。
- 当前通联大号呼号会为从未通联过的呼号显示“新”标记。
- 优化呼号播报去重，降低同一次发言重复播报的概率。
- 改进 `fmo.local` 地址规范化和连接测试稳定性。
- 便携 EXE 启动体验改为便携启动器语义，避免表现得像传统安装向导。
- 新增实时仪表盘页面，集中显示当前通联、最近通联、当前中继和刷新状态。
- 仪表盘调整为默认首页，打开后优先看到实时通联状态。
- 当前通联区域显示呼号、时间、QTH、相对方位、距离，并针对手机屏幕优化排版。
- 最近通联列表支持按呼号去重，最新一次发言优先显示。
- 最近通联列表显示 QTH，并将地址精简到省、市、区。
- 已在本地通联日志中出现过的呼号会在最近通联列表中显示小星星。
- 方位指针改为空心尖头样式，便于识别相对方向。
- 顶部发言状态支持短发言滞留显示，发言结束后保留最近呼号约 5 秒。
- 增加声音模式：新呼号提示、通联播报、关闭所有播报。
- 呼号播报优先使用女声，并降低播放速度，便于听清字母和数字。
- 中继名称可点击切换到对应 FMO 中继，已收藏中继显示星标。
- 使用系统中文字体替代大体积内置中文字体，显著降低首次打开流量和便携包体积。
