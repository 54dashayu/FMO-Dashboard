# FMO 仪表盘 V2.06.2

## 更新内容

- FMO 本次通联携带的有效网格或经纬度优先；缺少时回退到 APRS 最近位置，无位置保持“-”。APRS 最近位置不代表当前位置，不再显示具体时间。
- 识别 P.（Passport）、M.（M5 / ESP32）与 .R（RedDV）接入模式，规范基础呼号查询，避免将 AI- 等身份误套个人位置。
- 修复模式与中继列重叠、iPhone 竖屏上个通联地址裁切和英文待机标题拥挤。
- iOS 保留关闭自动/后台定位的设置，修复 iOS 27 生命周期启动并显示 App 备案号；客户端不内置 APRS 密钥。
- Android、Win64、macOS、网页显示版本统一为 V2.06.2。安装器/npm 使用标准版本 2.6.2。
- Win32 停止维护，本次不提供 Win32 安装包；官网 Win32 入口已撤下。

## 验证与限制

三个附件沿用本轮已公开校验的原始产物，不为统一 Release 重签或重打包。Android 构建 20802；Win64 来自 GitHub Actions 43059323455（fedbc28）；macOS 来自 43122140534（fba0dfa7）；iOS 构建 20805 由 App Store 分发，不附 IPA。

macOS 已在 Apple 芯片 Mac 启动验证，Gatekeeper 与公证装订校验通过；Intel 真机未测。Win64 按用户要求未操作 Windows 虚拟机，未做启动和升级验收。Android 本轮未做真机覆盖安装；不将构建成功等同于长期通联及全部机型验收。

`SHA256SUMS-V2.06.2.txt` 包含三个安装包的 SHA-256。旧版文件和历史 Release 保留用于回退；历史附件不代表继续维护 Win32。
